# StereoPolicy

Project page for **StereoPolicy: Improving Robotic Manipulation Policies via Stereo Perception**.

StereoPolicy studies how synchronized stereo observations can improve robot manipulation policies by providing geometry-aware visual representations without requiring explicit 3D reconstruction or calibrated depth sensing. The project evaluates stereo perception across diffusion-policy and vision-language-action policy settings, including simulation benchmarks and real-world tabletop and bimanual mobile manipulation deployments.

Website: https://stereopolicy.github.io/
